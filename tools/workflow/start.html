Einheitlicher Ablauf im Terminal

python3 x6.py doctor --profile research
python3 x6.py run signal --output runs/signal-001
python3 x6.py verify runs/signal-001
python3 x6.py export runs/signal-001 --output exports/signal-001.zip
python3 x6.py verify exports/signal-001.zip

run spectral führt fünf exakte rationale Referenzfälle aus. run rax reproduziert den veröffentlichten Benchmark und die Methodenprüfung. Für jeden Lauf einen neuen Ausgabeordner wählen.

Ein Exportpaket enthält run.json, summary.json, Protokolle und die vollständigen nativen Belege unter native/. Den Signalbericht unter native/signal/evidence.json können Sie direkt im Signal Lab importieren.

Vollständige Anleitung: docs/INTEGRATION.md im Checkout. Beenden des lokalen Servers: Strg+C.

Erfolgreiche Ausführung oder Nachrechnung ist keine physikalische Validierung. Die acht primären RAX-B1-Vergleiche bleiben unentschieden. Dieser Einstieg aktiviert keine Forschungsagenten oder Geräte.
