# Contributing

Please submit independent audit findings, bug reports and counterexamples via Issues. Code contributions intentionally submitted for inclusion are governed by Apache-2.0 section 5 unless explicitly stated otherwise or covered by a separate agreement. Submit only material you are authorized to contribute; identify third-party sources and preserve their licenses and notices. See [LICENSE](LICENSE) and [licensing scope](LICENSE_SCOPE.md). Include exact commands, inputs, revision SHA, environment, seed, expected/observed outputs and evidence. Do not upload secrets, private measurements or unredacted personal information. A numerical PASS is not a mathematical proof. See the community validation guide and code of conduct.
