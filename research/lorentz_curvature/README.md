# Krümmung: begrenzter Benchmark und Dichteverwechslung

Dieses Paket prüft zwei Ordnungsdiagnosen gegen eine bekannte 4D-de-Sitter-
Referenz. Der [vorab festgelegte Entwurf](DESIGN.md) trennt Modellabweichung
von eindeutiger Krümmungszuordnung. Der [Vertrag](contract.json) fixiert alle
Stichproben, Statistiken, Unsicherheiten und Abbruchregeln.

Die Quellen werden vor dem Zielversuch öffentlich fixiert. Ergebnisse und
Reproduktionshinweise folgen nach diesem unveränderten Lauf.
