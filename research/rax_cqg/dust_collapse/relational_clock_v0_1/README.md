# CST-DUST: Relationale Uhr und Kandidatenprüfung v0.1

Ein konkreter Ansatz aus kausal geordneten Uhrfeldern, chronologischer
Beschriftung, positiver Staubpräparation und lokalem L2-Produkt wird geprüft.
Seine Deutung als geschlossene normerhaltende Fortsetzung um genau ein
Element scheitert auf dem vollständigen erklärten Raum, auch für andere
beschränkte koerzive Produkte.

Die korrekte chronologische Zählung wird hergeleitet: Der frühere Faktor
1/e(P) fällt nach der Summation natürlicher Beschreibungen weg. Die
vorhergehende Monotonieselektion selbst ist eine Änderung des Trägers,
keine bloße Eichumbenennung.

88.324 markierte Darstellungen und 14.704 chronologische Kontrollrecords
bestätigen die Identität exakt. Der Normverlust nahe dem oberen Uhrregulator
wird allgemein bewiesen und durch 350 rationale Wellenpaketwerte geprüft.
Ein zusätzlicher Ausgang „keine Geburt“ ermöglicht ein Hilfsinstrument,
wählt aber keine physikalische Wartezeit oder Sektorgewichtung aus.

**Konkreter geschlossener Ein-Geburts-Kandidat: FAIL. Alle acht
übergeordneten physikalischen Gates: HOLD. Kein Bounce-Nachweis.**

## Nachrechnen

Python 3.10 oder neuer, Standardbibliothek, kein Netzwerk nötig:

```bash
python3 -O -B analyze.py
python3 -O -B replay.py
python3 verify_package.py
```

Die Uhrgitter und binären Dichtemarken sind eigenständige Kontrollmaße,
keine zertifizierte Quadratur des kontinuierlichen Pfadintegrals. Die
allgemeinen Aussagen folgen aus den ausgeführten Beweisen. Der lokale
gehashte Plan ist keine externe Präregistrierung. Die isolierte
Nachrechnung ist keine unabhängige wissenschaftliche Replikation.

Der nächste physikalische Schritt braucht eine begründete Zuordnung
zwischen festen relationalen Uhrwerten mit variabler Elementzahl und
expliziten Regeln für keine, eine oder mehrere Geburten. Ein freier
Instrumentabschluss genügt dafür nicht.
