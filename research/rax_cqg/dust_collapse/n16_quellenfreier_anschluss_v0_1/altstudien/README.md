# Neuberechnung der endlichen N15-Befunde

Neun Originalarchive enthalten die in den Pull Requests #339 bis #346 veröffentlichten Studien, ihre Prüfverträge, Eingaben, Programme, Referenzausgaben und Lizenzhinweise. Der gemeinsame Git-Stand ist der Merge von #346. Die Git-Blob-IDs aller neun Archive wurden beim Zusammenstellen am angegebenen Commit abgefragt. [GitHub-Stand 7aee15d1](https://github.com/thomasmgfeller/x6-spectral-astrolabium/tree/7aee15d1f269a2355991ea24a83a2127aecebb88/research/rax_cqg/dust_collapse/packages) · [Einzelpfade und Prüfsummen](quellen.json)

Im entpackten Verzeichnis mit Python 3.9 oder neuer ausführen. Der Standardlauf verwendet die Standardbibliothek und braucht Schreibzugriff auf den Ordner `altstudien` für das vorübergehende Entpacken.

```sh
python3 -B pruefen.py
```

Ein erfolgreicher Lauf gibt das Ergebnis als JSON auf der Standardausgabe aus und endet mit Exitcode 0. Er prüft für jedes Archiv SHA-256, Git-Blob-ID und die inneren Prüfsummen. Danach führt er 14 Originalprogramme auf ihren Eingaben aus und vergleicht sämtliche Felder der erzeugten JSON-Daten mit den veröffentlichten Referenzen. Vier zusätzliche Kontrollen im neuen Skript verwenden ausschließlich die veröffentlichten Eingaben bzw. bezeichneten Zwischenergebnisse und ihre eigene Implementierung. [Einstieg und Gegenrechnungen](pruefen.py)

Alle Referenzen auf frühere Artikelprüfungen bezeichnen endliche Modellrechnungen. Ein positiver Reproduktionsstatus ist von den Ergebnissen einzelner Hypothesentests zu unterscheiden. Insbesondere wird die Unverträglichkeit des scharfen Detektors mit der flach geschlossenen Naht reproduziert. Die physischen P3-Felder behalten ihren archivierten Status.

Für die zusätzlichen numerischen Gegenproben das betreffende Originalarchiv separat entpacken und die Befehle aus dessen README ausführen. Dort stehen auch die verwendeten Versionen von NumPy, SciPy bzw. mpmath und die Zahl der Stützstellen. Die beiliegende Datei `referenzlauf.json` hält die Ausgabe des Standardlaufs mit Python 3.12.14 fest.
