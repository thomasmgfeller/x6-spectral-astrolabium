2. Was ist dokumentiert?

Freier masseloser SJ-Gaußzustand auf festen 1+1-kausalen Mengen mit expliziten Nullmoden und Cutoffs. 13 Gegenprüfungen und bekannte Oszillatorentropie bestehen. 64 neue Ordnungen: Steigung 0,358, 95%-Intervall [0,260; 0,458]; vorab verlangte Präzision und Cutoff-Stabilität verfehlt (REFERENCE_NOT_ESTABLISHED). Kein nachgewiesener geometrischer oder industrieller Zusatznutzen.

  • research/free_field_entropy/RESULTS.md

    Vollständiger 64-Ordnungen-Befund, vorab fixiertes Kriterium, Cutoff-Empfindlichkeit und Grenzen.

  • research/free_field_entropy/analytic-validation.json

    Zwei-Oszillator-Referenz und 13 analytische/strukturelle Gegenprüfungen.

  • research/free_field_entropy/independent-audit.json

    Vier Größen mit getrenntem hermiteschem Kovarianz-Rechenweg; interne Prüfung, keine externe Replikation.

  • research/free_field_entropy/freeze.json

    Öffentlich vor dem Zielversuch fixierte Quellen und Analyse; früherer Pilot separat ausgewiesen.

Evidenzberichte behalten ihre eigenen Prüfrevisionen. Ein Quellenpin belegt weder einen neuen Lauf noch unabhängige externe Begutachtung.

3. Wie lässt sich das prüfen?

Python 3.12 unter Linux/POSIX; NumPy 2.3.5, SciPy 1.17.0 und threadpoolctl 3.6.0. Vollständiger Referenzlauf: maximal 30 Minuten und 2 GiB; kurze Prüfer ohne neue Zielstichproben.

In einem neuen Ordner ausführen; vorhandene Ausgabeordner nicht überschreiben. Voraussetzungen und paketbezogene Hinweise in der Originaldokumentation beachten.

git clone --branch main https://github.com/thomasmgfeller/x6-spectral-astrolabium.git x6-free-field-entropy
cd x6-free-field-entropy
git checkout --detach ced51c97b03525acc5d9ff907e175afce740974a
python3 -m pip install -r research/free_field_entropy/requirements.txt
OPENBLAS_NUM_THREADS=1 python3 -B research/free_field_entropy/test_core.py -v
OPENBLAS_NUM_THREADS=1 python3 -B research/free_field_entropy/check.py research/free_field_entropy/results
