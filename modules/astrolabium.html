3. Wie lässt sich das prüfen?

Python 3.12; gemeinsames setup --profile core. Browser-App: app/index.html.

In einem neuen Ordner ausführen; vorhandene Ausgabeordner nicht überschreiben. Voraussetzungen und paketbezogene Hinweise in der Originaldokumentation beachten.

git clone --branch main https://github.com/thomasmgfeller/x6-spectral-astrolabium.git x6-astrolabium
cd x6-astrolabium
git checkout --detach 26432e3d4cde20adabb510f17d5639891f4ac642
python3 x6.py run spectral --output runs/register-spectral
python3 x6.py verify runs/register-spectral

Erwartete Ausgabe

Exit 0; nur die unten genannte Softwareaussage.
