2. Was ist dokumentiert?

Gemeinsames synthetisches Verlust-, Polarisationsdrift- und Zeitmodell; affine Uhrkalibrierung mit getrennten Modellpulsen.

  • research/photonic-link/evidence/validation.json

    Gespeicherte Validierung; optionale RTL-Tests separat gekennzeichnet.

  • research/photonic-link/evidence/experiments.json

    Synthetische Szenarien mit Fehlfällen; kein gemessener Photonenlink.

Evidenzberichte behalten ihre eigenen Prüfrevisionen. Ein Quellenpin belegt weder einen neuen Lauf noch unabhängige externe Begutachtung.

3. Wie lässt sich das prüfen?

Python 3.12/venv und requirements; GHDL optional für zusätzliche RTL-Prüfung.

In einem neuen Ordner ausführen; vorhandene Ausgabeordner nicht überschreiben. Voraussetzungen und paketbezogene Hinweise in der Originaldokumentation beachten.

git clone --branch research/photonic-link https://github.com/thomasmgfeller/x6-spectral-astrolabium.git x6-photonic-link
cd x6-photonic-link
git checkout --detach 7ff72fcd6a16e9b353d1af277307463f757d3470
cd research/photonic-link
python3 -m pip install -r requirements.txt
python3 validate.py --output /tmp/register-plvl-validation.json
python3 experiments.py --output /tmp/register-plvl-experiments.json

Erwartete Ausgabe

Exit 0; nur die unten genannte Softwareaussage.

4. Was bleibt offen?

Modellparameter/Identifizierbarkeit mit realen Zeitstempeln, Verlust- und Driftmessungen prüfen; Fehlerbudget und unabhängige Kalibrierreferenz.
