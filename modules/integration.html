3. Wie lässt sich das prüfen?

Linux/POSIX x86-64, Python 3.12, Git, Node >=22; setup installiert gepinntes NumPy/SciPy. Browser für die Oberfläche.

In einem neuen Ordner ausführen; vorhandene Ausgabeordner nicht überschreiben. Voraussetzungen und paketbezogene Hinweise in der Originaldokumentation beachten.

git clone --branch main https://github.com/thomasmgfeller/x6-spectral-astrolabium.git x6-integration
cd x6-integration
git checkout --detach 8ee417ba8c44c1f32f4e310a6566168d84982d3a
python3 x6.py setup --profile research
python3 x6.py doctor --profile research
python3 x6.py serve

doctor: erfolgreich; serve meldet Loopback-URL und bleibt bis Strg+C aktiv.
