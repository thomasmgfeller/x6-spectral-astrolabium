3. Wie lässt sich das prüfen?

Python 3.12, Node >=22; setup --profile core. UI: app/signal-lab.html.

In einem neuen Ordner ausführen; vorhandene Ausgabeordner nicht überschreiben. Voraussetzungen und paketbezogene Hinweise in der Originaldokumentation beachten.

git clone --branch main https://github.com/thomasmgfeller/x6-spectral-astrolabium.git x6-signal-lab
cd x6-signal-lab
git checkout --detach ac519f5e4a83de0e570680fe4cfeb2da133db351
python3 x6.py run signal --output runs/register-signal
python3 x6.py verify runs/register-signal

Erwartete Ausgabe

Exit 0; nur die unten genannte Softwareaussage.
