# Experimental modules — scope after v0.2 remediation

Authoritative current contracts, metadata migration and commands are in README.md.

Implemented: finite pixel-centroid/RMS-width analysis, bounded CSV snapshot import,
explicit synthetic/recorded-unverified labels, typed scientific screening,
schema-plus-hash consistency verification, parameter snapshots, descriptive
statistics, and a classical Hamming(7,4) reference decoder.

Not implemented: hardware control, camera acquisition adapter, calibrated physical
drift inference, uncertainty budget, cryptographic attestations, immutable
storage, general experiment replay, GF-651 hardware, Sagnac tomography or a
quantum-computing performance claim. Changes remain isolated from app/index.html
and the running research pilot configuration and workflows.
