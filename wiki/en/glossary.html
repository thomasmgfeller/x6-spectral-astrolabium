Key terms

TermMeaning
SignalA sequence of values, usually over time.
SpectrumA representation of frequency components or, for a matrix, its eigenvalues. Context matters.
Fourier transform / FFTDecomposition into oscillating components; FFT is a fast method of calculating it.
PhaseThe position of an oscillating component within its cycle.
NoiseAdditional fluctuations; which components are unwanted depends on the task.
GraphNodes and their connections.
Laplacian matrixA matrix built from node degrees and connections; a precisely defined graph operator here.
Eigenvalue / spectral gapA characteristic value of an operator / a separation between specified eigenvalues. The intended gap must be defined.
Causal order / posetA set with a directed, transitive ordering; not every pair must be comparable.
Hasse diagramA drawing of the immediate relations of a finite order.
IsomorphismIdentical structure after a one-to-one renaming of nodes.
Invariant / fingerprintA feature unchanged by the allowed relabelling; it need not uniquely identify a structure.
Interval count KIn the proper-time experiment: the number of events strictly between two marked events.
Height HThe length of a longest chain; counted in nodes here.
Relation densityThe fraction of comparable pairs under the specified counting convention.
Minkowski modelA flat relativistic spacetime model, without curvature.
1+1 dimensionsOne time dimension and one spatial dimension.
Proper timeA measure of time along a timelike connection; relative to an outer scale in this experiment.
SeedA starting specification for a reproducible random sequence.
BaselineA specified comparison method.
Control / counterexampleA test case for a particular error risk / a case refuting a general claim.
HoldoutData not used to fit or select a method.
BootstrapRepeated sampling from existing data to estimate a particular uncertainty.
RMSERoot mean square error.
CommitA precisely identified version of a Git project.
Pull request / PRA proposal to incorporate changes into another development branch.
CIAutomatically executed integration and checking workflows.
Replay / replicationRecomputing a result / repeating a finding; scope and independence must be stated.
Provenance / hashDocumented origin / a checksum of bytes.
Continuum limitA mathematically controlled passage from discrete objects to a continuous limiting model.

One word can have several meanings

A graph spectrum is not the same as the frequency spectrum of a measured vibration. Likewise, a spectral gap is not automatically a physical energy gap. Always check which operator, unit and model are involved.
