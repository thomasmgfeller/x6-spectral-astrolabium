# Provenance

`app/index.html` and test artifacts were extracted from the X6 v4.3 community audit ZIP supplied in the development history. That ZIP includes the actual X6 v4.2 release-candidate HTML, not a newly certified v4.3 application. Historical result JSON is archival evidence, not newly executed independent verification. Browser script path and local Python output path were adjusted for repository layout. Repository scaffolding does not validate the underlying physics or mathematics.
